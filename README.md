# PTIT Focus Statistics - ระบบแปลงข้อมูลและแดชบอร์ดสถิติปิโตรเลียม (DMF)

ระบบจัดการ แปลงข้อมูล และวิเคราะห์สถิติการผลิต การจำหน่าย และมูลค่าปิโตรเลียมของประเทศไทย จากรายงานประจำเดือนของ **กรมเชื้อเพลิงธรรมชาติ (DMF)** จัดทำโดย **สถาบันปิโตรเลียมแห่งประเทศไทย (PTIT)**

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **Dashboard & Data Visualization:**
   - แดชบอร์ดสรุปสถิติปริมาณการผลิต (BOED, MMSCFD, BPD) และมูลค่าการจำหน่าย/ค่าภาคหลวง
   - กราฟแนวโน้มรายเดือน (Monthly Trends) และการเปรียบเทียบแยกตาม Operator / พื้นที่ (Onshore vs Offshore)
   - เจาะลึกสถิติประจำเดือน (Monthly Deep-Dive) และ Market Share
   - เลือกดูรายเดือนหรือสรุปรายปีได้ทั้ง Production และ Sales; รายงานจัดแหล่งปิโตรเลียมเป็นมิติหลักและแสดงผู้ดำเนินการเป็นข้อมูลประกอบ โดยปีที่ข้อมูลยังไม่ครบจะแสดงยอดสะสมตั้งแต่ต้นปี (YTD) พร้อมระบุเดือนล่าสุดที่มีข้อมูล
   - รายงาน Sales สรุปปริมาณแยกตามผลิตภัณฑ์และแหล่ง พร้อมยอดรวมรายเดือนทั้งประเทศ โดยไม่บวกปริมาณต่างหน่วยเข้าด้วยกัน
   - ส่งออกรายงาน Excel ตามช่วงเวลาที่เลือก โดยใช้ชื่อรายงานและหน่วยมาตรฐาน PTIT
2. **ระบบแบ่งสิทธิ์ผู้ใช้งาน (Role-Based Access):**
   - **Viewer (ผู้ใช้งานทั่วไป):** เข้าถึงเฉพาะหน้าแดชบอร์ดสถิติและรายงานมาตรฐาน พร้อมปุ่มดาวน์โหลด Flat Table
   - **Admin (ผู้ดูแลระบบ):** ปลดล็อกฟังก์ชันการแปลงข้อมูล, จัดการ Master Data Model และระบบ 1-Click Auto Sync
3. **ระบบ 1-Click Auto Sync (In-Memory Stream):**
   - ตรวจจับเดือนใหม่และดึงข้อมูลสดจากเว็บไซต์กรมเชื้อเพลิงธรรมชาติ (dmf.go.th) เข้าสู่หน่วยความจำ RAM โดยตรง
   - คำนวณและปรับปรุงตัวเลขย้อนหลังอัตโนมัติ (Retroactive Adjustments)
   - **ซิงก์ทุกปีที่ DMF เผยแพร่** (การผลิตตั้งแต่ปี 2546, การจำหน่ายตั้งแต่ปี 2003) ผ่าน GitHub Actions ทุกวัน
     - เก็บข้อมูลที่แปลงแล้วแยกรายปีไว้ที่ `data/cache/production/<ปี พ.ศ.>.json` และ `data/cache/sales/<ปี พ.ศ.>.json`
     - แต่ละรอบจะดาวน์โหลดใหม่เฉพาะปีล่าสุดและปีก่อนหน้า (เผื่อ DMF แก้ตัวเลขย้อนหลัง) และเดือนที่ยังไม่มีในแคช
     - ถ้าต้องการดาวน์โหลดใหม่ทุกปี ให้รัน workflow ด้วยตัวเลือก `force_refresh` หรือตั้ง `FORCE_REFRESH=1` ตอนรัน `python .github/scripts/sync_dmf.py`
     - หน้าเว็บโหลดปีล่าสุดมาก่อน ส่วนปีอื่นจะโหลดจาก `frontend/public/data/<production|sales>/<ปี>.json` เมื่อเลือกปีนั้น
     - ตาราง Excel รวมทุกปีอยู่ที่ `output/petroleum_production_flat_table_all_years.xlsx` และ `output/petroleum_sale_flat_table_all_years.xlsx`
     - ข้อมูลน้ำมันดิบแหล่งฝาง (DEDP) รวมเฉพาะปีที่มีค่าใน `fang_production_master.*`
4. **มาตรฐานรายงาน PTIT (Domestic Production Report):**
   - ส่งออกรายงานการผลิตในประเทศรูปแบบทางการตามมาตรฐานสิ่งพิมพ์ PTIT (.xlsx)
5. **ติดตามรายแหล่งข้ามปี & ตาราง Mapping แหล่ง (Field Group Mapping):**
   - หน้าเว็บ "ติดตามรายแหล่ง (Field Tracker)" เลือกได้สูงสุด 4 แหล่ง ดูแนวโน้มรายเดือน/เฉลี่ยรายปีตั้งแต่ปี 2546 พร้อมส่งออก Excel
   - DMF เปลี่ยนชื่อ/สะกด/รวม/แยกแหล่งหลายครั้ง (ปี 2559 และช่วงเปลี่ยนสัมปทาน 2565–2566) จึงมีไฟล์ `field_group_mapping.xlsx` ให้ทีม PTIT กำหนด "กลุ่มติดตาม"
   - แก้ไขได้ที่แอป Streamlit (Admin) → การผลิตปิโตรเลียม → แท็บ **จัดการ Master List** → **🔀 3. จับคู่แหล่งข้ามปี** หรือเปิดไฟล์ Excel แก้ตรงๆ
   - ระบบใช้เฉพาะแถวที่ **สถานะ = ยืนยันแล้ว** · แถว **ร่าง** แสดงบนเว็บเป็นข้อเสนอแต่ไม่ถูกคำนวณ · ชื่อแหล่งใหม่จาก DMF จะถูกเพิ่มเป็น "ร่าง" ให้อัตโนมัติ
   - เมื่อ push ไฟล์ Mapping (หรือ `fang_production_master.*`, `master_mapping.xlsx`) ขึ้น GitHub ระบบซิงก์จะรันเองและอัปเดตเว็บภายในไม่กี่นาที
   - ไฟล์ Excel รวมทุกปีมีคอลัมน์ `กลุ่มติดตาม` สำหรับนักวิเคราะห์

## 🚀 วิธีการติดตั้งและรันระบบ (Quick Start)

### 1. ติดตั้ง Dependencies
```bash
pip install -r requirements.txt
```

### 2. รันแอปพลิเคชัน
```bash
streamlit run app.py
```
หรือดับเบิลคลิกไฟล์ **`เปิดระบบแปลงข้อมูล.bat`** บน Windows

## 📁 โครงสร้างโปรเจกต์ (Project Structure)
```text
├── app.py                      # สคริปต์หลักของ Web Application (Streamlit)
├── dmf_live_stream.py          # โมดูลเชื่อมต่อสตรีมข้อมูลสดจากเว็บ DMF
├── master_mapping.xlsx         # ตาราง Master Data Model การผลิต
├── sale_master_mapping.xlsx    # ตาราง Master Data Model ยอดขายและค่าภาคหลวง
├── requirements.txt            # รายการ Dependencies สำหรับรันระบบ
├── output/                     # โฟลเดอร์เก็บไฟล์ผลลัพธ์ Flat Table (.xlsx)
├── Sale/                       # โฟลเดอร์เก็บไฟล์รายงานยอดขาย DMF
└── คู่มือการใช้งาน.md          # คู่มือการใช้งานระบบฉบับละเอียด
```
